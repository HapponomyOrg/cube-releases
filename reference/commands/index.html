Commands

No. 013

The commands of cube 0.1.0. The tables and the help below are what cube itself prints: cube --help lists the commands, and cube <command> --help prints the help of one. Where the help names the plan of a later release, this page says “a later release”.

Commands

Section titled “Commands”
Command What it does
cube tools List the installed tool binaries
cube adopt Take over an existing KB without changing its content files: write .cube/cube.toml, .cube/cube.lock, the hook shims in .cube/hooks/ and the agent skill in .claude/skills/cube/, and commit them
cube check Run every check: the native checks and the kit’s checks; exit 1 when any finding is an ERROR; –format agent prints the fix brief. Writes nothing but the index cache of an adopted KB
cube doctor Check the environment: git, runtime.python, the hooks, cube.path, safe.directory, the machine-local config.yml in the kit’s machinery folder, the formats and the kit’s tools; exit 3 when an item fails
cube setup Set up the git hooks: write cube.path and the absolute git, gh and python3 paths into the global git config, and merge.ff=false and core.hooksPath=.cube/hooks into the clone
cube hook Run by the installed git hooks: the checks, the ratchet and the trailers
cube ls List every indexed file as the Explorer’s tree knows it: path, kind, app, title, and a spec’s state
cube show Show one file’s preview and facts: title, tl;dr, kind, front matter, and a YAML file’s loaded fields
cube inbox List the agent acts awaiting acknowledgement and the malformed Cube-Act trailers, read-only (acks arrive in a later release)
cube skill Render the agent skill from this cube’s command line, check registry and kit.yml, and install it into the KB
cube pack List, add or remove the layer packs of the KB’s kit; never commits
cube help Print this message or the help of the given subcommand(s)

Exit codes

Section titled “Exit codes”
Code Meaning
0 ok
1 ERROR findings: cube check found one, or a hook refuses the commit
2 a usage or configuration error
3 an environment error: a missing tool, an incompatible kit or engine, or a command that is not built yet

Tools

Section titled “Tools”

Any other name runs a tool binary, cube-<name>, from the folder of this cube; cube tools list shows the installed ones. The kit names cube graph (cube-graph ^0.1), cube index (cube-index ^0.1); cube <tool> --help shows a tool’s own commands.

Not in this release

Section titled “Not in this release”

These names are reserved for commands that later releases bring. In this release, cube <name> refuses with exit 3 and says that the command is not built yet, and cube --help does not list it. No tool program can take one of these names.

Command What it will do
cube init Create a new KB from a kit
cube new Create a node from a kit template
cube set Edit one field of a node
cube transition Move a node to another lifecycle state
cube drift Draft an as-built block
cube accept Accept an as-built block
cube reject Reject an as-built block
cube ship Flip a spec to SHIPPED when its work is merged
cube ack Acknowledge agent acts
cube run Run a kit sequence
cube delete Remove a node after an impact check
cube mv Move files or spec folders and rewrite references
cube status Print the dashboard’s data
cube query Run a kit query
cube branch Manage KB variants
cube diff Show a KB-level diff
cube merge Merge KB variants
cube fork Derive a KB with lineage
cube upstream Sync with the parent KB
cube kit Update the kit machinery
cube session Open, resume or close a session
cube agent Launch an agent
cube app Manage apps and their code folders
cube score Print the harness self-score
cube classify Show the classification of a path
cube prune Prune untracked files past retention
cube log Show the lifecycle log of a node
cube self Update or roll back the engine
cube migrate Run content and format migrations
cube tools update Update installed tools
